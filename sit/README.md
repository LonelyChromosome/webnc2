# LAB LR2 - Function Component trong React

Chạy bài:

```bash
cd sit
npm install
npm run dev
```

Cấu trúc chính:

```text
src
├── components
│   ├── Header.jsx
│   ├── Footer.jsx
│   ├── NewsItem.jsx
│   └── NewsList.jsx
├── App.jsx
├── App.css
└── main.jsx
```

Bài đang ở trạng thái cuối của PHẦN E: `App.jsx` sử dụng `Header`, `NewsList`, `Footer`; `NewsList.jsx` chứa ba `NewsItem`.
