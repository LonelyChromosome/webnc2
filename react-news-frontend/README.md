# React News Frontend (LAB RN)
Backend: Express REST API (LAB 11) at http://localhost:3000
Frontend: React/Vite at http://localhost:5173

Run from repository root: npm install, npm run dev.
Or run individually: npm start (root), cd react-news-frontend && npm run dev.

Features: /posts, /posts/:id, /posts/create, /posts/:id/edit, /login, /contact; Axios withCredentials true; login/logout and persistent cookie session; CRUD using REST API. Existing MVC/EJS and sit/ labs remain untouched.
Create an account at http://localhost:3000/users/create then log in at http://localhost:5173/login.
